# 사건 재료

사건의 무대와 인물 이름은 이 폴더의 데이터에서 무작위로 뽑아 조합합니다. AI는 정해진 무대와 이름에 이야기와 기록 문장만 입힙니다. 항목을 추가하고 서버를 다시 켜면 바로 쓰입니다.

한 사건은 이렇게 만들어집니다.

1. **방 구조** 하나와 **테마** 하나를 고릅니다. 바로 앞 사건과 같은 테마는 피합니다.
2. 방 구조의 6칸 중 하나를 무작위로 **사건 현장**으로 정하고, 테마의 `scenes` 중 하나를 그 이름으로 붙입니다.
3. 나머지 5칸에는 테마의 `rooms`에서 무작위로 5개를 골라 붙입니다.
4. **이름**에서 피해자 1명과 용의자 5명을 뽑습니다. 한 사건 안에서는 성이 겹치지 않고, 최근 사건에 나온 이름은 피합니다.

`maps/` 폴더의 직접 그린 지도(배경 이미지가 있는 지도 등)도 함께 섞여 나옵니다.

## layouts.json: 방 구조

방 6개의 위치와 크기만 적습니다. 이름은 테마가 붙입니다.

```json
{
  "name": "격자형",
  "aspect": [16, 10],
  "rooms": [
    { "x": 2, "y": 3, "w": 30, "h": 40 },
    ...방 6개
  ],
  "doors": [[0, 1], [1, 4]]
}
```

| 항목 | 필수 | 설명 |
| --- | --- | --- |
| `name` | | 구조 이름 (확인용) |
| `rooms` | O | 방 **정확히 6개**. `x, y, w, h`는 지도 전체를 0~100으로 본 퍼센트 |
| `aspect` | | 지도의 가로:세로 비율. 생략하면 `[16, 10]` |
| `doors` | | 통로로 이어진 방 쌍(방 순서 번호, 0부터). 생략하면 **맞닿은 방끼리 자동으로** 잇습니다 |

사람은 30분에 통로로 이어진 옆방까지만 움직입니다. 모든 방이 통로로 이어져 있어야 하고, 아니면 서버를 켤 때 오류가 납니다. 어느 방이든 현장이 될 수 있습니다.

### 자동 생성

`"auto": true`가 붙은 구조는 생성 스크립트가 만든 것입니다. 큰 사각형을 가로나 세로로 반복해서 잘라 방 6개를 만들고, 일부는 맞닿아 있어도 문이 없는 벽을 둡니다. 통로 연결 검사를 통과하고, 어느 방이 현장이 되어도 사건을 만들 수 있는 구조만 남깁니다.

```bash
node scripts/gen-layouts.js 100   # 손으로 만든 구조를 포함해 100개가 될 때까지 채움
```

다시 돌리면 자동 구조만 새로 바뀌고, 손으로 만든 구조(`auto` 표시 없음)는 그대로 남습니다.

## themes.json: 테마

```json
{
  "name": "출항 첫날의 크루즈",
  "theme": "출항 첫날 밤의 호화 크루즈선",
  "scenes": ["선장실", "기관실", "VIP 객실"],
  "rooms": ["갑판", "연회장", "카지노", "바", "선실", "조타실"],
  "icons": { "바": "🍸", "카지노": "🎰" }
}
```

| 항목 | 필수 | 설명 |
| --- | --- | --- |
| `name` | O | 화면에 보이는 무대 이름 |
| `theme` | O | 사건 배경. AI가 이야기를 쓸 때 참고합니다 |
| `scenes` | O | 사건 현장이 될 수 있는 방 이름 (1개 이상) |
| `rooms` | O | 나머지 방 이름 후보 (**5개 이상**, 많을수록 다양해집니다). 방 이름은 8자 이내 |
| `icons` | | 방 이름별 이모지. 생략한 방은 이름으로 자동 선택하고(서재 📚, 주방 🍳 …), 맞는 게 없으면 🚪 |

## names.json: 이름

| 항목 | 설명 |
| --- | --- |
| `surnames` | 성. 지도 칩에 성만 보이므로 한 사건 안에서는 겹치지 않게 뽑습니다. **6개 이상** 필요합니다 |
| `given` | 이름. 성과 무작위로 짝짓습니다 |
