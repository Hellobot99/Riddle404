# 직접 그린 지도

평소에는 `data/`의 방 구조와 테마를 무작위로 조합해 무대를 만듭니다([data/README.md](../data/README.md)). 이 폴더는 **방 이름과 배치가 고정된 지도**를 직접 만들 때 씁니다. 예를 들어 평면도 이미지를 배경으로 깔고 싶을 때예요.

이 폴더의 `*.json` 파일 하나가 지도 하나입니다. 서버를 켤 때 모두 읽고, 조합 지도와 함께 섞어서 씁니다.

## 형식

```json
{
  "name": "눈 덮인 산장",
  "theme": "눈보라에 갇힌 산장의 생일 파티",
  "aspect": [16, 10],
  "image": "/maps/mansion.png",
  "rooms": [
    { "name": "서재", "scene": true, "x": 2, "y": 3, "w": 30, "h": 44 },
    { "name": "계단", "x": 34, "y": 3, "w": 16, "h": 44 },
    { "name": "온실", "x": 52, "y": 3, "w": 46, "h": 44 },
    { "name": "거실", "x": 2, "y": 50, "w": 46, "h": 47 },
    { "name": "주방", "x": 50, "y": 50, "w": 22, "h": 47 },
    { "name": "현관", "x": 74, "y": 50, "w": 24, "h": 47 }
  ]
}
```

| 항목 | 필수 | 설명 |
| --- | --- | --- |
| `name` | O | 지도 이름. 브리핑 화면에 보입니다. |
| `theme` | O | 사건 배경. AI가 인물과 이야기를 쓸 때 참고합니다. 예: "출항 첫날 밤의 크루즈선" |
| `rooms` | O | 방 **정확히 6개**. 그중 하나에 `"scene": true`를 붙이면 그 방이 사건 현장(404)이 됩니다. |
| `rooms[].name` | O | 방 이름, 1~8자. 방끼리 겹치면 안 됩니다. |
| `rooms[].icon` | | 방 한가운데 깔리는 이모지 하나. 예: `"icon": "🍷"`. 생략하면 방 이름으로 자동 선택합니다(서재 📚, 주방 🍳, 온실 🌿, 서버실 🖥️ …). 맞는 게 없으면 🚪. |
| `rooms[].x, y, w, h` | O | 방의 위치와 크기. 지도 전체를 0~100으로 본 **퍼센트**입니다. 왼쪽 위가 (0, 0)입니다. |
| `aspect` | | 지도의 가로:세로 비율. 생략하면 `[16, 10]`. 배경 이미지를 쓰면 이미지 비율과 맞추세요. |
| `doors` | | 통로로 이어진 방 쌍. 예: `[["서재", "계단"], ["거실", "주방"]]`. 생략하면 **맞닿은 방끼리 자동으로** 잇습니다(사이 간격 4 이하, 맞닿은 변이 3 이상 겹칠 때). |
| `image` | | 배경 이미지. 파일은 `public/maps/`에 넣고 `"/maps/파일이름.png"`처럼 적습니다. png, jpg, webp, svg를 쓸 수 있습니다. 생략하면 격자 배경에 방 상자만 그립니다. |

## 통로와 이동 규칙

사람은 30분 동안 제자리에 있거나 **통로로 이어진 옆방**으로만 움직입니다. 그래서 방 배치가 곧 추리 재료가 됩니다. 예를 들어 사건 현장과 이어지지 않은 방에 있던 사람은 30분 뒤 현장에 있을 수 없습니다.

- 통로는 지도 위에 작은 막대로 표시되고, 사건 현장으로 이어지는 통로는 빨간색입니다.
- 모든 방은 통로로 이어져 있어야 하고, 현장과 이어진 방이 하나 이상 있어야 합니다. 아니면 그 지도는 건너뜁니다.
- 현장과 이어진 방이 적을수록 범인의 동선이 좁아져 추리가 쉬워집니다.

## 배경 이미지를 쓸 때

1. 평면도 이미지를 그리거나 생성해서 `public/maps/`에 넣습니다.
2. 이미지에서 각 방이 차지하는 영역을 퍼센트로 재서 `x, y, w, h`에 적습니다. 예를 들어 1600×1000 이미지에서 (32, 30)부터 480×440 크기인 방은 `x: 2, y: 3, w: 30, h: 44`입니다.
3. 방 상자는 이미지 위에 반투명하게 겹쳐 그려지고, 그 안에 관측 결과가 표시됩니다.

## 확인

서버를 켤 때 콘솔에 읽은 지도 목록이 나옵니다. 형식이 틀린 지도는 이유와 함께 건너뜁니다.

```
지도 3개: 심야의 연구소, 눈 덮인 산장, 개관 전야의 미술관
지도를 건너뜀 - ship.json: rooms는 정확히 6개여야 함
```
